# EzBox 📦

**EzBox** es una aplicación móvil nativa para Android diseñada para la gestión rápida y eficiente de inventario y control de stock, integrando escaneo de códigos de barras y almacenamiento local para un funcionamiento *offline-first*.


## Funcionalidades Principales

* **Gestión de Inventario:** Alta, modificación y control general de productos y categorías.
* **Escaneo de Códigos de Barras:** Identificación rápida mediante cámara utilizando ML Kit.
* **Almacenamiento Local:** Persistencia de datos en el dispositivo para operar sin conexión a internet, ademas de cloud-syncs en momentos de disponibilidad de red.

## Tecnologías

* **Lenguaje:** Kotlin
* **Plataforma:** Android Nativo
* **Arquitectura:** MVVM (Model-View-ViewModel)
* **Base de Datos:** Room
* **Escáner:** Google ML Kit / CameraX
